Custom channels override the standard OBD value for a gauge. Use them to read the MSD80/MSD81 DME directly (e.g. header 6F1, CAN extended address 12, receive 612). The app never ships guessed DME identifiers. Add ones you have verified for your DME software. Each entry: target (rpm | boost | boostTarget | rail | coolant | wg1 | wg2), header, cea, cra, request (hex, e.g. 22XXXX), formula using response bytes A,B,C… (after the echoed request). Output units: boost/rail in kPa (absolute for boost), coolant °C, wastegate %.
